# User Common

## Overview
This module provides the shared domain models and enumerations for user management within the Intelligent Personal Trainer platform.

## Key Features

*   **User Model:** Defines the core `User` entity shared between the User Service and other consuming services.
    *   Personal Attributes: Age, Height, Weight, Gender.
    *   Authentication Data: Username, Password (handled securely).
*   **Lifestyle Enumerations:** Defines standardized classifications for user lifestyles (e.g., Sedentary, Active) to support personalized AI recommendations.
*   **Health Attributes:** Structures for capturing user diseases or health conditions.
